## Где и как использовался ИИ
Использовал ИИ как помощник. Раньше я писал тесты на готовом фреймворке, а собирать структуру с нуля мне приходилось впервые, поэтому ИИ помог в следующем:

1. ИИ помог реализовать `BaseClient`  и предложил структуру pydantic-модели для валидации.
2. Помог разобраться с ошибками запуска: сериализация модели в `json=` (`model_dump()`), `null` в PATCH (`exclude_unset=True`), передача `Response` вместо JSON.
3. Давал ревью моих тестов
4. Тесты на некорректный payload (`POST /posts`): пустой payload, отсутствующее поле, неверный тип значения. Реализованы с помощью ИИ: у меня пока немного опыта с негативными тестами, поэтому я не уверен, что подход выбран оптимальный.

## Установка требований
```bash
pip install -r requirements.txt
```

## Запуск тестов
```bash
pytest                    
pytest -m smoke
pytest -m full
pytest -m negative
```
